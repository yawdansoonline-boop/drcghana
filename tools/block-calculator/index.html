💡 TIPS
  • Bigger block = fewer needed. 600×250 ≈ 6.3/m² vs 450×225 ≈ 9.3/m²
  • Count blocks on delivery – don't trust the driver's word
  • If Unaccounted > 0, ask your contractor where blocks went
  • Mortar included: effective = block + 10mm mortar
  • Door (0.9×2.1m) ≈ 19 blocks; Window (1.2×1.2m) ≈ 14 blocks
  • Order 5–10% extra for breakage – waste is normal
  • Std Ghana 450×225 ≈ 9.3/m² with 10mm mortar
